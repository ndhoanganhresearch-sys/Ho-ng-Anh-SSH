# Box Short Test Dataset

Centered box-shaped tunnel dataset with 4 evenly spaced defect spots.

- Use `T0_box_short.las` / `.txt` as reference.
- Use `Tn_box_short.las` / `.txt` as monitoring.
- Coordinates are centered near the origin and LAS offsets are zero.
- Designed to exercise import, clean-noise, sections, Step 6, warnings, and export. Use `full_test` for target registration.
